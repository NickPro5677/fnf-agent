2. ¿Quién juega?

¿Quién juega?

Vacía = distinta cada vez. Con un número, el bot repite la misma partida.

Estás en la demo web (https). El navegador no deja que esta página se conecte a ws://127.0.0.1. Para jugar con una IA, abre el juego en local: python -m http.server 8000 -d web y entra a http://127.0.0.1:8000.

En Termux: python agente/relay.py y luego python agente/agente_chart.py.
